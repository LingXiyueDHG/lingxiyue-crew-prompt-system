# 灵汐月的剧组体系提示词

像真实剧组一样产出镜头提示词的 Windows 桌面应用。你输入自然语言，系统按真实制片顺序（原作者 → 编剧 → 导演 → 摄影 → 美术 → 声音 → 总导演终审）让每个角色各跑一遍 LLM，每个角色只写自己职责范围内的字段，最终镜头提示词由所有角色的贡献组装而成，并可按目标模型方言（Z-Image-Turbo、MiniMax H3 等）渲染输出、推送到 ComfyTV 画布。

本仓库为**分发版**：包含安装包与安装说明。

## 功能简介

- **剧组流水线**：每个角色独立 LLM 运行、独立规则包（rulepack），下游角色只看到自己声明的上游依赖
- **镜头树**：编剧运行自动把作品拆成场景/镜头，可手动增删、排序
- **可追溯**：每次运行不可变存档、带版本号；上游重跑后下游自动标记 stale
- **方言渲染**：镜头保存为结构化提示词对象，按需渲染成不同模型方言文本，可多方言并排预览
- **ComfyTV 推送**：通过 MCP 把镜头映射为 ComfyTV stage 参数，幂等创建/配置节点
- **MCP 服务**：系统自带 agent/bot 开关，关闭即旁路（bypass），不干扰其他 agent 正常使用
- **桌面形态**：无控制台窗口，关闭主窗口后驻留系统托盘

## 安装要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 运行时 | Microsoft Edge WebView2（安装器会自动检测，缺失时自动安装官方运行时） |
| LLM 后端 | 任意 OpenAI 兼容接口（推荐本地 [llama.cpp](https://github.com/ggml-org/llama.cpp) server，默认端口 8080） |
| 磁盘 | 约 150 MB |

## 安装步骤

1. 下载 `release/crew-setup.exe`（约 28 MB）
2. 双击运行。若 Windows SmartScreen 弹出"未知发布者"警告，点"更多信息 → 仍要运行"（安装包未做代码签名）
3. 向导会自动检查 WebView2 运行时；缺失时选择"是"自动安装
4. 选择安装位置（默认当前用户 Programs 目录，无需管理员权限），勾选"创建桌面快捷方式"
5. 安装完成后可直接启动

## 首次运行

1. 打开软件后，在底部**设置栏**填写你的 LLM 接口：
   - 本地 llama.cpp 示例：启动 `llama-server -m 你的模型.gguf --port 8080`，设置栏填 `http://127.0.0.1:8080/v1` 与模型名
   - 设置栏会自动探测端口 8080 上已有的 OpenAI 兼容服务并尝试连接
2. 新建项目 → 输入自然语言 → 编剧运行会自动生成镜头树
3. 各角色按流水线顺序运行；LLM 未连接时界面会明确报错提示

## 数据与卸载

- 所有项目数据保存在 `%APPDATA%\crew`（与安装目录解耦，换安装位置不影响历史）
- 卸载通过 Windows"添加或删除程序"；卸载只删程序文件，**不会删除**你的项目数据
